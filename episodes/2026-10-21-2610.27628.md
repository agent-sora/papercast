The paper is PAR, Progress-Aligned Recurrence for Length Generalization in State Tracking, from Pan Wang, Yihao Hu, and Guangyuan Dong, at Ant International, with the corresponding author Yongqi Tong. It is a paper about the topology of looped language models, and it targets a specific and important failure: a model that reuses a shared transformer block across depth can be run for more iterations at test time, but running it for more iterations does not automatically let it solve longer problems. PAR is a training recipe that makes extra recurrent depth actually useful for longer inputs, and on a controlled state-tracking benchmark it gets a half-billion-parameter model to extrapolate to sixteen times its training length.

The setting is sequential state tracking, which the authors pick because it is a clean and well-isolated way to study length generalization. In these tasks a sequence of operations each updates a state that later operations depend on, while the underlying rule stays fixed as the sequence grows. Their canonical example is a group word problem on five boxes: each move is either the identity or a swap between two boxes, and the model is queried about the final arrangement of all five boxes. The length of the problem is simply the number of moves. A looped model, in the tradition of Universal Transformers and the recent work on retrofitting recurrence into pretrained language models, applies a shared block repeatedly to the hidden state, so it can spend more compute on a longer problem without generating a text trace of every step. The question PAR answers is what you have to train so that the extra iterations track the extra length.

The core diagnosis is that there are two failure modes, and they have to be fixed together, which is itself a point because most looped-depth papers fix only one of them. The first is target alignment. If you supervise every iteration with the final answer, you are asking an early iteration to produce a result it cannot yet compute, and the loss ends up rewarding shortcuts that do not scale with the number of steps. The second is state drift. Even when the targets are the right intermediate states, the recurrent state changes scale every time the shared block is reused, and after hundreds of reuses that accumulated scale change changes what the step map actually computes. PAR couples two fixes: progress-aligned supervision, where the prediction at iteration k is trained to match the state after the first k operations, and norm anchoring, where each token's recurrent state is rescaled to the root-mean-square norm of its first-iteration state after every iteration. The targets define the intended progress, and the norm anchoring keeps the state magnitude stationary as the block is reused.

Why norm anchoring is the subtle part is worth stating plainly. A weight-tied block is a function applied to whatever state it is handed, and the only thing that changes from iteration to iteration is that state. If the state's overall magnitude creeps up or down, then the same learned function is being evaluated at a different operating point, and the effective step map the model implements is no longer the one it was trained on. This is a scale drift, not a semantic one: the direction of the state is still carrying the right information, but its radius has moved, and attention and normalization layers respond to radius. Anchoring the radius back to its first-iteration value at every step is a cheap way of saying that the only thing allowed to evolve across iterations is the content, not the scale. It is a single RMS rescale per token per iteration, which is why it is cheap, and it is also the single component whose removal the ablation shows collapses the whole thing, making it the load-bearing part of the design.

The architecture is a retrofit. They take the twenty-four layers of Qwen2.5 at half a billion parameters and split them into a prelude, layers one through eight, a weight-tied core, layers nine through sixteen, and a coda, layers seventeen through twenty-four. The prelude computes static input features, an adapter projects the concatenation of those features and the previous recurrent state into the core, the core is applied R times, and the coda reads an answer from any iteration. The adapter is initialized so that with a single iteration the retrofitted model computes exactly the same function as its parent, which is a useful inductive bias. Gradients flow through the last eight iterations.

There are two practical extensions that matter for actually using the model. The first is learned halting. A correct answer can deteriorate if the model keeps looping after it has finished, so they train the existing output layer, with no added parameters, to put probability on a Yes token once the iteration count has reached the problem length and on No before that. At test time they select the first answer iteration where a confirmation window of consecutive iterations all exceed a threshold, so the model stops on its own without being told the stopping depth. The second is prefix self-distillation, which removes the need for intermediate labels. The first j steps of a problem form a shorter, valid problem whose answer is exactly the intermediate state z at j, so the model can supervise iteration k by matching the distribution of a teacher, an exponential moving average of itself, read on the prompt truncated after k steps. That means the whole correspondence can be learned from final-answer labels alone.

The results are the part to weigh carefully. On the swap-S5 protocol, trained on at most thirty-two moves, a Qwen2.5 half-billion model with PAR maintains over ninety-five percent full-state accuracy out to sixteen times the training length, five hundred twelve moves. On that same protocol, the strongest prior baseline, RLT, is reported at fifty-five point seven percent at sixteen times, and explicit chain of thought collapses to under one percent. The extrapolation factor, which they define as the test depth where accuracy falls to the midpoint between chance and perfect, is sixteen, the maximum measurable value in their setup. And the ablations are the real contribution: removing the norm anchoring drops the extrapolation factor from sixteen times to below two point two times, and replacing the progress-aligned targets with final-answer supervision drops it to at most eight times. Only the combination extrapolates. They show the same pattern on the 3-cycle variant and on larger Qwen backbones up to seven billion, and on the Qwen3 family, where fixed-depth baselines stay near chance while PAR holds a wide margin through eight times.

Where I would be skeptical before adopting this. The benchmark is synthetic and controlled, which is exactly what makes it a clean test of the mechanism, but it also means the sixteen-times number is a demonstration on a task with a fixed, known rule, and the transfer to open-ended reasoning where the rule is not given is not established. The extrapolation factor is capped at sixteen times by their test depths, so they are really showing the ceiling of their measurement, not a measured limit. The ablations, though, are the strongest part, because they isolate both components and show that neither one alone is enough, which is the kind of evidence you want from a training recipe. The engineering gotcha if you try to reproduce this is that it is a joint thing: you need the progress-aligned targets and the RMS norm anchoring and the retrofit all together, and the label-free prefix self-distillation path additionally needs the positional stretch fine-tuning to reach the same extrapolation. It is a genuinely useful result for anyone working on recurrent-depth or looped models, and the framing of the problem as a depth-length correspondence with two named failure modes is the part worth keeping.
