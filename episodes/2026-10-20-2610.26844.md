The paper is AnyGoal, on world model generalization beyond expert rollouts, from Heejeong Nam, Divyat Mahajan, and Quentin Le Lidec, at Brown University, Cold Spring Harbor Laboratory, Mila at the University of Montreal, and New York University. The question it asks is a specific one about world models, the models that learn how an environment evolves under actions so that an agent can plan and simulate before acting. The appeal of a world model is that it captures dynamics, not task-specific behavior, so it should let an agent plan new tasks without collecting new rollouts. But for that to hold, the learned dynamics have to behave well beyond the specific state and action combinations seen in the training rollouts, and that is the property the paper argues has never been properly tested, because in-distribution evaluation gives you almost no evidence that the model learned reusable dynamics. It can score well on the training goal while having only memorized the behavioral bias of the expert that generated the data.

The framing is compositional generalization. Can a world model recombine familiar state factors and familiar actions into valid dynamics, even when that particular combination was underrepresented in the expert trajectories? That is the gap AnyGoal targets, and it is a carefully constructed one. The test tasks are designed so that every individual state factor and every action stays within its training support, so nothing physically novel is introduced, but the joint combination of state and action is rare in the training data. The model is being tested on recombination, not on out-of-distribution physics.

The reason this distinction matters is that expert rollouts are not random. A policy that solves one task produces trajectories with strong correlations between states, objects, and actions, the agent approaches the block before pushing it, it moves through the narrow passage, it carries the peg toward the target. A world model trained only on those rollouts sees those joint combinations over and over, and it can learn a shortcut, a prior that says what happens in this state given the expert's typical action, without learning the actual effect of each action in each state. In-distribution evaluation rewards exactly that shortcut, because the test distribution matches the training correlations. The goal-shifted variants break the correlation while keeping everything else in support, which is the only way to separate a learned mechanism from a memorized behavioral bias.

AnyGoal builds on four widely used world-model environments: TwoRoom, a two-room navigation task; Push-T, where an agent must push a T-shaped block to a goal; a Manipulator peg-insertion task; and a cube benchmark. For each base task it generates goal-shifted variants, one free-space variant and one or two contact-rich variants, and releases 400 episodes per variant along with the data-collection tools for generating more. The paper is explicit about how it validates that a variant stays within the combinatorial space. It runs three factor-wise support checks, a range check, a Mahalanobis check against the reference mean and covariance, and a kernel density estimate check, and requires 95 percent of the query samples to pass. All variants pass those marginally-in-distribution checks. Then, separately, it measures the joint overlap between the target distribution and the base-task joint support with a full-dimensional kernel density estimate, and the target variants sit well below the in-distribution threshold, which confirms they cover the combinatorial gap the paper wants to probe.

The evaluation is relative. Each world model is trained only on the base dataset and then evaluated on both the base task and the goal-shifted variants, so the change in rollout prediction error and downstream planning success directly measures how much the dynamics generalize to the unseen state-action combinations. Because the same trained model is used for both evaluations, the comparison controls for model capacity, training budget, and architecture, and isolates the goal shift as the only variable. The model families tested span the current landscape, including video-prediction world models like Dino-WM, latent world models like LeWM and DriftWorld, and oracle-state predictors, so the result is not an artifact of one architecture family. The headline finding is consistent and unambiguous: across multiple environments and multiple world-model families, current models fail under these recombinations. The clearest example is Push-T, where a model trained to push a T-shaped block toward a goal performs poorly on the inverted task, avoiding the block, even though the avoiding task requires only familiar two-dimensional navigation with individually familiar states and actions. On the planning numbers, a model that plans well on the base task can drop to near zero on the goal-shifted one. The paper frames this as a degenerate response, the model collapsing onto a default behavior instead of using the learned dynamics.

The paper does two things that push beyond just reporting the failure. First, it separates dynamics failures from representation failures. It runs oracle-state experiments, where the model is given the true physical state directly rather than a learned latent representation, and the goal shift still hurts, especially in the contact-rich settings. That rules out the explanation that the failure is just the visual encoder producing a bad latent, because even with the correct state the dynamics do not transfer. The model is failing at the transition function, not at perception. Second, it measures action sensitivity. It intervenes on the action input while holding the state fixed and measures how much the predicted representation changes, which is a direct test of whether the model responds to the supplied action or to the behavior policy's preferred transition. The result is that action sensitivity drops in the regions where the expert behavior is strongly biased toward the goal. In TwoRoom, where the expert always moves through the narrow passage, in Push-T, where it approaches before pushing, and in the peg task, where it carries the peg toward the target, the model becomes less responsive to the actual action. That is the signature of a shortcut. The model has learned the goal-directed prior, the tendency of the expert to head toward the goal, rather than the reusable effect of each action.

What I would trust here is the rigor of the construction. The three-check validation that the variants are marginally in-distribution, the separate joint-overlap measurement showing they sit in the combinatorial gap, and the oracle-state experiment that isolates dynamics from representation are all exactly the right controls, and they are the part that makes this more than a benchmark that is hard by accident. The action-sensitivity analysis is also a genuinely useful diagnostic, because it gives you a number you can measure to tell whether a world model is learning mechanisms or memorizing the behavior policy, and the fact that the released package includes the data-collection tools means you can generate your own goal-shifted variants for an environment you care about, which is the difference between a one-off analysis and a reusable evaluation harness. What I would re-verify: the environments are all small, low-dimensional control tasks, so the conclusion that world models fail to generalize compositionally is well supported in that regime but does not transfer to high-dimensional, high-observation settings like image-based world models, which is where the field is actually heading. The paper is a benchmark and an analysis, not a fix, and it does not propose an architecture that solves the problem, so it is a diagnosis without a treatment, and the authors frame the open directions as identifying reusable mechanisms from offline rollouts and adding structural assumptions for extrapolation. And the contact-rich failures are the most pronounced, which means the hardest, most realistic interactions are exactly where current world models are weakest. A skeptical read: this is a clean, well-controlled demonstration that in-distribution world-model evaluation is misleading, and the action-sensitivity metric is a contribution you can reuse. But it is a negative result in a low-dimensional setting, so it tells you where the field's current methods break, not how to fix them.
