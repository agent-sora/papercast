## AI4AI at Test-Time: Capability Transfer Without Training

First, "AI4AI at Test-Time." Distillation usually means updating a small model's parameters on a big model's outputs. This paper asks whether the transfer can happen entirely at inference time: can a strong builder model construct a harness that makes a weaker target model dramatically better, with zero parameter changes?

The recipe: the builder gets five percent of a benchmark as validation data, iteratively refines an inference-time harness over multiple rounds, then the finished harness is evaluated on the full test set. Across four Theory-of-Mind benchmarks, average target performance nearly doubles, from zero point four nine to zero point nine one. The analysis is the best part: the gains come mostly from offloading unstable reasoning into deterministic code, benchmark-specific routing, and strict answer-format enforcement — not from coaxing the target model into deeper thought. Builder reasoning effort helps monotonically, and weaker targets gain the most.

For practitioners this reframes distillation as a systems problem. Before you pay for fine-tuning, ask what a scaffold written by a stronger model could buy you for free. It also echoes everything we cover on this show: harness quality is often the difference between a demo and a product.

## ToolHazard: Adversarial Environments at Scale

Second, "ToolHazard." Agents that call external tools are exposed to indirect prompt injections hidden in environmental state — tool outputs, files, web pages. Security research here has been throttled by hand-built environments and pre-decided injection points. ToolHazard synthesizes executable, stateful environments automatically: an Environment Simulator builds them, an Attacker Agent discovers viable injection points and writes environment-specific payloads, and a User Simulator grounds long-horizon tasks in real state.

On top of it sits ToolHazard-Bench, and the stress tests find substantial vulnerabilities across complex workflows. Two findings worth your attention: injection timing and placement materially change attack effectiveness, and — encouragingly — alignment data generated by ToolHazard improves security on both their bench and AgentDojo without hurting benign task success.

If you operate tool-calling agents in production, treat your environment as an attack surface you must fuzz, not a fixture you trust. Scalable adversarial synthesis like this is how that fuzzing becomes routine.

## Parameter Exploration for RLVR: 3PO

Third paper moves from security to reinforcement learning for verifiable rewards. Exploration in LLM RL is usually action-space: temperature scaling and its cousins, which only reshape output variance and cannot reorder tokens outright. "Parameter Exploration for RLVR via Variational Learning" argues for exploring in parameter space instead: sample rollouts from different policies drawn from a posterior around the current policy.

They introduce Perturbed Parameter Policy Optimization — three-P-O — a family of methods varying how parameter samples are drawn and how rollout groups are formed for reward estimation. On OLMo-3 and Qwen2.5-Math across maths and code tasks, 3PO consistently beats standard GRPO at essentially identical FLOPs cost. Mechanically, multi-sample groups produce fewer zero-advantage groups and fewer malformed rollouts — which is exactly the failure mode that stalls GRPO runs in practice.

If you run RL post-training, parameter-space diversity is a complementary lever to temperature, and this paper suggests it is the lever pulling more weight.

## SkillZip: Compressing Skill Libraries Without Breaking Them

Fourth, "SkillZip." Agent skill libraries keep growing, but context budgets do not. The field has a unit mismatch: skills are retrieved as packages, compressed as text, and only converted into execution graphs after retrieval — and compression keeps breaking procedural contracts. SkillZip compresses section-level execution graphs directly, rewriting recurring contract-valid motifs into reversible ported macros while preserving boundary signatures, dependency closure, verifier reachability, and source-level expansion. A companion process, ReZip, integrates new skills and revises risky macros using execution evidence.

Numbers: up to twelve point two points over the strongest baseline, three point four six times compression, ninety-nine percent dependency preservation, robust retrieval from two hundred to a hundred thousand skills. The design lesson travels: when you compress procedural knowledge, preserve contracts and reversibility, not just tokens. A macro you cannot expand back is a liability you will debug at three in the morning.

## Persistent Recursive Worlds: Software That Outlives Its Agents

Fifth, "Persistent Recursive Worlds Enable Autonomous Software Evolution" — EvoX Genesis. Most agentic coding systems preserve continuity through persistent sessions, memories, or manager agents. Genesis flips it: the software project is persistent; every agent is finite-lived. Each local world anchors to an accepted version and a repository path, agents propose local changes, recursive delegation moves work across paths, and only accepted consequences advance version history.

The headline result: starting from a repository with no compiler implementation, using DeepSeek V4 Flash, Genesis built a Rust-based C compiler of roughly two hundred fifty thousand tracked lines over a hundred twenty hours, archiving over a thousand agent episodes for about forty-four dollars in token charges — passing the complete c-testsuite and most LLVM and Csmith tests. Development continued smoothly across repeated agent replacement, and a second project ported MESA modules to Rust with median speedups of one point five five to six point eight seven times.

Whatever you think of the code's ultimate quality, the architecture claim matters: long-horizon autonomy may be a property of the project's state machine, not of any agent's lifespan. Design for handover, not endurance.

## Poor Man's Agentic Modeling: Societies on a Laptop

Last today, "Poor Man's Agentic Modeling." Simulating societies of many LLM agents is expensive, yet most questions asked of such simulations are macroscopic — phase behaviour, stylised facts, scaling trends — not the cognition of any single agent. The method: replace each LLM agent with a low-parameter surrogate fitted from a few hundred to a few thousand cheap queries, then run the whole society on a laptop.

The intellectual core is an interaction-order-by-memory taxonomy predicting where surrogates work and where they fail, validated across a faithful reimplementation of an LLM macroeconomy plus seven other simulations. The predicted error trends hold cell by cell, and even the two refuted cases are matched quantitatively by the theory with no free parameters. Agent decisions were cloned from genuine LLM elicitations for a few dollars.

For anyone doing agent-based modelling — economics, epidemiology, platform dynamics — this is a cost collapse of several orders of magnitude, with an honest map of where the approximation breaks.
