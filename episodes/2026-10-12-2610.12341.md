Can AI Agents Learn Their Way to the Top, Evaluating Heuristic Learning in a Long-Running Game Agent Competition, from Kaisen Yang, Qingle Liu, and Kejin Wang at Tsinghua University. The premise is that adversarial games have been a testing ground for AI for decades, from hand-crafted heuristics and tree search through reinforcement learning and self-play, but a hard sub-problem has persisted: learning and adapting a strategy from limited samples when the opponents are themselves changing. The agents form part of the environment, and every shift in their strategy moves the learning target. The paper's alternative to gradient-based reinforcement learning is what it calls heuristic learning, the idea that you can keep the model weights completely fixed and instead treat the AI agent as a learning engine that turns game experience into revisions of executable game policies and their supporting software. They formalize this as adversarial heuristic learning, and they build a benchmark to measure it.
The benchmark, AAArena, has three parts. First, twelve authentic adversarial games, and this is where the design gets concrete. The games vary in number of players, symmetry, and information structure. There are two-player symmetric games like Pacman, SnakeGo, AntWar, Generals, Miracle, and AntWar 2. There is an asymmetric two-player game, Rollman. There is a four-player game, LostSpace. And several games have partial or hidden information, like MoneCraft, AquaWar, Dorado, and LOTA. The authors order the games by the size of their rule specification, measured in abstract syntax tree node count, which gives a clean axis for studying how performance degrades as rules get more complex. Second, the benchmark archives one thousand nine hundred twenty human programs, real game agents that human players built and played, which become the opponents the AI has to climb past. Third, there is a unified two-budget evaluation protocol modeled on real game competitions, with fixed match and evaluation budgets. Under the protocol, the agent reads the rules, picks opponents, analyzes match replays, and revises its own game agent and supporting code, trying to reach the highest possible ranking. The model weights never change; all the learning is in the code the agent writes and edits. They evaluate seven model and harness configurations across the games.
The comparison set in Figure 1 is worth dwelling on, because it is what makes the gold-medal result meaningful. The paper benchmarks seven model-and-harness configurations, and the figure plots each against a Human SOTA reference point per game. The configurations span current-generation systems, including GLM-5.3, Kimi K3, Qwen 3.8, DeepSeek V4 Pro, LongCat 2.0, GPT 6 Sol, and Opus 5.5 with the Claude Code harness, and the games are laid out in ascending order of rule complexity by abstract syntax tree node count. That ordering is the paper's way of showing the degradation axis empirically: the right side of the figure, the games with larger rule specifications, is where the configurations cluster lowest and where the human ladders stay hardest to top. The games with the largest rule specifications in the set sit in the upper thousands of AST nodes, and that is roughly where the human programs retain their rank-one positions.
The results are the most interesting part of the paper. Opus 5.5 with the Claude Code harness is the strongest configuration, and it earns six gold medals, meaning rank-one finishes in six of the twelve games. But no evaluated configuration tops the human ladders in the remaining six games, so the human-written programs still hold the top rank in half the board. The authors note that performance is generally weaker in the games with more complex rule specifications, which lines up with the rule-size axis they set up earlier. The ablations are where the mechanism of the learning actually shows. For opponent selection, they compare four strategies: letting the agent choose its opponents, a ladder that starts at rank thirty and only moves toward stronger opponents, random sampling from the pool, and playing only the four highest-ranked opponents. All use dense feedback and a small-match batch size of four. The ladder leads on Pacman and AntWar, while the agent's own model-selection choice leads on Miracle. Model selection beats both random and top-four in all three games they report, so letting the agent pick opponents that give it useful information matters, not just playing the strongest available. For feedback density, they compare detailed small-match replays, with state, action, and consequence, against binary win or non-win feedback. Dense feedback yields a higher retained-champion Elo in all three games, which supports keeping the diagnostic replay context rather than reducing the match history to a score. They also show the agents improve from both on-policy replays of their own matches and off-policy replays of other players' matches, so the learning is not locked to self-play. The qualitative analysis points to the remaining weaknesses, which is the kind of failure taxonomy a team building a game agent would actually use to prioritize their next round of revisions. What makes the negative result harder to dismiss is the construction of the human baselines themselves. The one thousand nine hundred twenty archived human programs were not collected for a single game; they span the twelve-game set, and each human ladder is the aggregate of what real players actually shipped into the competition over time, not a single hand-tuned expert. That matters because it means the comparison is against a long tail of human heuristics, many of which are idiosyncratic and hard to generalize across, which is exactly the regime where a language model writing code from scratch would be expected to struggle. The fact that the best model configuration still does not top six of the twelve ladders, even after the harness has all of the code-generation and iteration machinery of a frontier agentic system, suggests the gap is not a matter of more compute or a bigger model, but of the kind of game-specific, low-level heuristics that a general-purpose model does not naturally produce. There is also a methodology point worth flagging. The evaluation is a competition over a fixed, finite set of games, and the human ladders are the accumulated product of players who had the specific incentive to grind those exact games. A model that has not been tuned to the peculiarities of each of the twelve games is being compared against humans who, collectively, have. So the result is best read as a statement about where frontier coding agents currently sit on the long tail of specialized game strategy, not as a ceiling on what such agents could reach with game-specific training data.
The skeptical read. The whole result is bounded by the harness and the model inside it. A gold medal is the agent, with a particular coding model and a particular tool loop, producing a game program that beats one thousand nine hundred twenty human programs under a fixed match budget, which is a real but narrow claim. The two-budget protocol means the agent has limited interaction, so the learning is closer to a handful of directed revisions than to open-ended self-play, and the gap to the human SOTA in the harder, more complex games is exactly where the heuristic-learning idea is supposed to shine. The human programs are archived and fixed, so the moving-target, adapting-opponents problem that motivated the paper is only partially represented, the ladders are static archives rather than live evolving populations. Bottom line: AAArena is a well-constructed benchmark and the finding that fixed-weight agents can earn rank-one finishes in half of twelve real games, with opponent selection and dense replay feedback as the key levers, is a concrete and reproducible demonstration of heuristic learning. I would want the human ladders to be live and evolving, and I would want to see the gap in the most complex-rule games close, before treating this as more than a strong coding-agent result dressed in a game-competition frame.
