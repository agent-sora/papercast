Nemotron-Labs-Diffusion-Uni, or NLD-Uni, by Shufan Li, Hanrong Ye, and Greg Heinrich, from NVIDIA, with the remaining authors, including the senior researchers, all at NVIDIA. This is a foundation-model release, a unified discrete diffusion large language model that does both visual understanding and visual generation in one set of weights, and the interesting question is whether the distillation recipe that gets it there is one you can actually transfer to your own model.

The model is a discrete diffusion LLM, which means it generates tokens through a denoising process rather than the left-to-right autoregressive pass that a standard language model uses. The novelty is that it is unified: the same model reads an image and answers a question about it, and it also generates an image from a text prompt, and it can do the interleaved thing where it reasons, locates an object, and then edits the image. The internal representation is a set of vector-quantized tokens for images and ordinary text tokens for language, and the model uses a joint attention mechanism over both, so the image and text streams attend to each other within a single transformer rather than being bolted together through a connector. That is the elastic unified diffusion model architecture, and it is the substrate the distillation and the progressive corruption both act on. The two major contributions are the training recipe and a change to how the diffusion process works during training. The first is a unified cross-paradigm on-policy distillation framework, which is the meat of the paper. On-policy distillation is a known technique for improving the visual understanding of autoregressive vision-language models and the generation of continuous flow models, and this paper is the one that adapts it to a unified masked diffusion model. The key move is cross-paradigm: the understanding teacher is an autoregressive vision-language model, and the generation teacher is a continuous rectified-flow model, and the student is a discrete diffusion model that is neither. So the student is being distilled from two teachers that use fundamentally different generation paradigms, and the distillation has to bridge the gap between autoregressive and continuous into a single discrete student. The on-policy part is the part that matters in practice: rather than training the student to match the teacher's output on a fixed dataset, the student generates its own sequences and the teacher scores those student-generated sequences, which means the student is learning from the distribution it actually produces at inference rather than from a distribution it will never visit. That distinction is what makes on-policy distillation work for a diffusion student, because a diffusion model's intermediate states are not a fixed set of targets, they are a trajectory the model itself takes, and matching a teacher on off-distribution trajectories would teach the student to behave correctly on states it does not actually pass through.

The second contribution is a change to the corruption schedule. Conventional masked diffusion corrupts a clean image token directly to an uninformative mask token in one step, and NLD-Uni instead uses a progressive self-refining process that gradually corrupts each token across multiple steps during training. The practical consequence, which is the point, is that at inference the model can make an intermediate commit to a token, so it does not have to generate the whole image in one denoising pass, it can lock in a token and then refine the rest around it, which the paper reports improves visual quality. That intermediate commit is the elastic part of the name, because it lets the model spend more compute where the image is harder and less where it is not, rather than using a fixed denoising schedule. The contrast with the canonical masked process is worth being precise about: in the standard formulation the corruption is a single jump from a clean token to a mask token, so the model has no intermediate states to learn from and cannot revisit a token it has already produced, whereas the progressive schedule inserts a sequence of intermediate corruption levels that the model sees during training, which is what makes the intermediate commit possible at inference, because the model has been trained to behave sensibly at every corruption level rather than only at the endpoints.

On the numbers. The model is state of the art among unified diffusion language models across visual question answering, multimodal reasoning, object grounding, text to image generation, and image editing. On the understanding side, it beats prior unified diffusion models and diffusion vision-language models by a considerable margin on MMMU, ChartQA, and InfoVQA, and on object grounding it is strong on RefCOCO and the GUI grounding benchmark ScreenSpot-Pro. The aggregate numbers put its multimodal understanding accuracy at seventy eight point three, compared to sixty one point two for the prior state of the art, and its text to image GenEval score at four point one seven against three point nine two. The delta over the prior diffusion state of the art is large in absolute terms on several tasks, with gains in the ten to forty nine point range depending on the benchmark. The paper is honest about one thing: they do not use an on-policy distillation teacher for the text to image task, because the base model is already stronger than the candidate teachers like Qwen-Image and Flux on GenEval, so the generation side is not actually distilled, it is trained directly. The interleaved task is where the two ingredients come together: the model reasons in text, locates an object with grounding, and then edits the image, and the paper reports strong results on the image editing benchmark ImgEdit, which is the task that genuinely exercises the unified understanding-generation loop rather than either capability in isolation, so it is the benchmark that most directly supports the claim that one set of weights can do both jobs.

Here is the skeptical read. The cross-paradigm distillation is the contribution, and it is a real one, but the paper does not isolate how much of the gain comes from the distillation versus the base model scale versus the progressive corruption change, and without that attribution it is hard to know which ingredient you would actually need to reproduce the result. The comparison set is strong, it includes BAGEL and the prior unified diffusion models, but it is a comparison against unified diffusion models and diffusion vision-language models, and I would want to see it against the strongest autoregressive unified models at the same parameter count, because the autoregressive paradigm still dominates a lot of the high-end unified benchmarks, and a win over the diffusion class is a different claim from a win over the best unified model full stop. The intermediate commit at inference is a nice design, but it is a variable-length process, and the wall-clock cost of deciding when to commit is not reported as a clean latency number, which matters because a diffusion model that has to spend extra denoising steps on hard images is slower exactly when you least want it to be. The honest admission that text to image is not distilled is the right thing to say, but it means one of the two headline tasks is not actually an example of the cross-paradigm recipe working, so the recipe is really demonstrated on the understanding side and the interleaved editing side, and the text to image result is a base-model result.

The bottom line: this is a credible foundation-model release for a unified discrete diffusion model, and the cross-paradigm on-policy distillation from an autoregressive teacher and a continuous teacher into a discrete student is the genuinely new idea, even if the attribution between the three ingredients is not fully separated. If you are exploring unified models and want a non-autoregressive option that handles understanding, generation, and interleaved editing in one set of weights, this is the current state of the art in the diffusion class, and the progressive corruption with intermediate commit is a concrete inference-time trick worth understanding before you decide whether the discrete diffusion paradigm is worth the complexity for your application.
