The paper is Seeing, Maintaining, and Learning: The Evolution of Multimodal Agent Memory, from Minghao Guo, Qingyue Jiao, and Xiujin Liu, a large collaboration spanning Rutgers, Notre Dame, the University of Michigan, Fudan, Carnegie Mellon, KAIST, and NVIDIA, among a long list of other institutions. It is a position and survey paper, and its contribution is a two-axis analytical framework for how multimodal agents should form, represent, and manage memory as they move from short tasks toward long-horizon and lifelong settings.

The problem is that multimodal agents are expected to keep acquiring useful information from complex, heterogeneous data, images and video and audio and text, across sessions, and to keep getting better at it. The memory mechanism is what has to support that, and the paper argues the field has been treating memory as a grab-bag of techniques rather than something with a coherent structure. Their move is to split the question into two axes. Axis I is formation and representation: what information is retained, and how it is encoded. Axis II is memory management: how that memory is maintained, updated, and used as experience accumulates. The paper then works each axis in turn, synthesizing the recurring design patterns in the literature and deriving a set of principles for each.

On Axis I, the survey organizes representations into four families. The first is source- and modality-specific representations, where each modality keeps its own encoding, an image embedding for the image, an audio embedding for the audio. The second is cross-represented explicit memory, where experience is stored as textual or structured records that can be shared across modalities, like a caption or a structured scene description. The third is internalized latent and parametric memory, where the experience is folded into the model's own latent states or weights, the same territory as the consolidation papers that bake context into parameters. The fourth is hybrid representations that mix these. The point of the taxonomy is that each family makes a different trade-off between fidelity to the source and the compactness and transferability of what is stored, and the right choice depends on what the downstream reasoning or action actually needs. A modality-specific embedding preserves fine perceptual detail that a text record will throw away, but it is hard to reason over and hard to search. A structured record is queryable and composable, but it loses the parts of the observation that were never worth writing down. A parametric memory is the most compact and the most general, because it can be used without any retrieval step, but it is the hardest to inspect and the hardest to correct, which is precisely why the consolidation literature is so interested in how to control what goes in and what stays out.

On Axis II, the survey defines three tiers, and this is the part I would actually use. Tier one is static memory: fixed memory that is stored once and reused, with no update policy. It is fast and predictable, but it cannot adapt when the environment or the user changes. Tier two is dynamic memory: memory that is updated by a stable policy, a fixed rule for what to add, what to revise, and what to forget. Tier three is self-evolving memory: the memory policy itself learns and changes over time from the outcomes of using it. The paper's framing is that these are a ladder of increasing adaptivity, and that the interesting frontier is the climb from tier two to tier three, where the agent not only updates its memory but improves the way it decides what to remember. The authors illustrate the whole lifecycle with a household-robot example, where the same observation, an object moving from one shelf to another, produces different memory states under each tier, and where a placement rule learned at tier three generalizes to new furniture.

The framework also carries a claim about granularity of the memory unit, and that is where the two axes interact. A static image can be stored at the level of the whole image, a region, a single object, or the scene as a whole, and the choice changes what the downstream task can do with it. A video or audio stream can be stored as keyframes, as clips, as events, as object tracks, or as temporally aligned audiovisual segments, and the paper treats these as design choices on Axis I, not as implementation details. The point is that the granularity decision is not free: finer granularity keeps more source information and makes provenance and recovery easier, but it also makes the memory larger and harder to retrieve from, while coarser granularity compresses better but throws away the evidence you would need if a decision built on it has to be explained later. That trade is exactly what the fidelity-versus-abstraction principle is trying to name, and it is the one a practitioner is going to hit first, because every real agent has a fixed context budget and a fixed latency budget, and the memory design has to live inside both of them at the same time. The paper's running example of a household robot illustrates this concretely: the same observed experience can be formed as a verbatim record, as an abstracted skill, or as a parametric update, and then managed under each of the three tiers, and the choice of cell in that grid determines both what the robot can do later and what it can be held accountable for when it does it. From the two axes the paper distills a set of principles. Balance source fidelity against abstraction, so the memory is detailed enough to be useful but abstract enough to generalize. Maintain temporal validity and provenance, so the agent knows when a memory is still true and where it came from. Ground memory use in recoverable evidence, so a decision built on memory can be traced back to the original observation. And evolve the memory policy over time, which is the tier-three ideal. These are reasonable and mostly uncontroversial, which is appropriate for a survey, but they are the part that gives the framework some normative content rather than leaving it as a pure taxonomy.

Now the skeptical pass. The two-axis framework is only as useful as its discriminating power, and I would want to see it applied to a concrete system: pick a real agent with a real memory implementation and check whether the framework actually tells you what to change, or whether every design choice maps to a cell in the matrix without any guidance about which cell is better. The tier-three self-evolving tier is the aspirational claim, and the paper should be explicit about how much real evidence exists for memory policies that improve themselves from outcome feedback, as opposed to how much is extrapolation from lifelong-learning results in simpler settings. The principle of balancing fidelity and abstraction is the one that will matter most in practice, and it is the one that is stated least operationally, because there is no general metric for the right level of abstraction, so in a real system that decision is going to be empirical and task-specific. One more limitation is worth naming: the framework is organized around what a memory system does, not around how expensive it is. A tier-three self-evolving policy that updates itself from outcomes is computationally much more demanding than a tier-two fixed policy, and for a deployed agent with a latency budget the tier choice is going to be as much a resource decision as an architectural one, but the paper does not attach cost to the tiers. The author list is enormous, which signals a community-wide effort to define the area, and that is a strength for coverage but also a sign that the field is consolidating around a vocabulary faster than it has settled on methods. I would read this as the map to orient a research program in agent memory, and then go directly to the primary papers behind each cell of the framework for the actual technical detail.

Bottom line: a broad, well-organized framework for multimodal agent memory that splits the problem into formation and representation versus management, and that ladders memory from static to self-evolving. It is a taxonomy and a set of principles rather than a method, so it will not move any benchmark, but it gives the area a shared vocabulary and a clear picture of where the open problems are, which is exactly what an early field needs.
