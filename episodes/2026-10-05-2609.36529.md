Title: Triadic Linear Attention: Three-Dimensional Recurrent States for Long-Context Sequence Modeling
Authors: Oliver Sieberling, Bharat Runwal, David Jin
Labs: Massachusetts Institute of Technology; MIT-IBM Computing Research Lab
Arxiv: 2609.36529
Day: 2026-10-05
Upvotes: 3

Triadic Linear Attention is from Oliver Sieberling, Bharat Runwal, and David Jin at the Massachusetts Institute of Technology and the MIT-IBM Computing Research Lab. It is an architectural change to linear attention that grows the recurrent memory state from a two-dimensional matrix to a three-dimensional tensor, in order to give recurrent models more capacity for long-context recall without a proportional increase in parameters. This is squarely in the territory of alternative attention mechanisms, and it generalizes the construction that made linear attention work in the first place.

The starting point is the role of the memory state in a recurrent model. A recurrent neural network compresses its entire history into a fixed-size state, which is what gives it constant-time inference, and the size of that state is a first-order determinant of how much context the model can actually recall. A model with a fixed-size state literally cannot copy back a sequence longer than its state can hold. Linear attention, which has seen a real resurgence, works by upgrading the ordinary vector-valued hidden state of a standard RNN to a matrix-valued one. It does that efficiently by writing to the state with the outer product of the key vector and the value vector, so the matrix accumulates key-value associations across the sequence. The paper's observation is that this outer product is a special case of a more general construction, and that you can go one dimension higher.

The core idea is to write a triadic outer product instead of a pairwise one. Instead of the outer product of a key and a value, which fills a matrix, the model writes the outer product of a key, a second key, and a value, which fills a third-order tensor, a three-dimensional state. Reading works by contracting both key axes with two queries. The key design property is parameter efficiency. An E-dimensional second key gives an E-fold increase in the size of the state while adding only two additional projections to the model. That is the whole appeal. You are getting more memory for very little extra parameter cost, because the capacity comes from the state's shape, not from more weights. They keep E small, on the order of 8, which is exactly the regime where the parameter overhead stays tiny.

The construction is not just a shape change, it composes with the other things that make modern linear attention work. It is compatible with data-dependent forgetting, where a per-slice decay gate controls how much of the previous state survives each step. It is compatible with the delta rule, the error-correcting write that lets the model overwrite specific associations rather than just accumulating them. And it has a chunkwise-parallel training form, so the recurrence can still be parallelized across the sequence length for efficient training, which is the property that makes these models trainable at scale in the first place. So it drops into existing Gated DeltaNet and scalar-gated linear attention architectures rather than requiring a new training stack.
There is one number that frames the entire contribution, and it is the parameter-cost number. Going from the baseline linear attention to the triadic version with a second-key dimension of 8 adds only about 1.2 percent more non-embedding parameters, while the state capacity grows by a factor of 8. That is the trade that makes the method interesting, a near-flat parameter cost for an order-of-magnitude state-size gain. The capacity scaling is the point, and the parameter cost is deliberately kept to a rounding error.

The experiments test the method on two scales. The smaller is a 400-million parameter model with 24 layers, a model dimension of 1024, and 8 heads. The larger is a 1.3-billion parameter model with 24 layers, a model dimension of 2048, and 16 heads. They pretrain each model on 50 tokens per parameter, which is a standard and modest pretraining budget. The comparison is against alternatives that also enlarge the state, because the relevant question is not whether a bigger state helps, it always does, but whether the triadic construction gets more recall per parameter than the obvious alternatives, like naively widening the head dimension or adding more heads to grow the state.

The results show that the triadic construction substantially improves long-context language modeling and recall compared to those state-enlarging alternatives, at the same or lower parameter cost. The recall improvement is the clean signal, because recall is exactly the task where a fixed-size state is the bottleneck, and it is where a bigger, better-shaped state should pay off. The gains are consistent across the two scales, which matters more than any single number, because it says the construction transfers from 400 million to 1.3 billion parameters rather than being an artifact of one configuration.

There is an engineering cost that the paper is honest about. The three-dimensional state is bigger in memory, and they note that the state of a single head occupies 512 KiB in 32-bit floating point, which is twice the register file of a typical GPU block, versus 128 KiB for the baseline. That is a real hardware constraint, and it is the price of the extra dimension. The chunkwise-parallel implementation is what makes it tractable, but the memory footprint of the state is something you have to plan around, and it grows with E, so the sweet spot is keeping E small, which is why they use 8.

The skeptical read. The parameter-efficiency argument is the strong part, and the 1.2 percent overhead for an 8-fold state increase is a genuinely attractive ratio that the obvious alternatives do not match. The concerns are the training budget and the memory cost. Fifty tokens per parameter is a light pretraining regime, so the models are small and undertrained in the way that can exaggerate the relative benefit of a better state, because recall tasks are where undertrained models are weakest. The two scales tested, 400 million and 1.3 billion, are both well below frontier scale, and the state-memory footprint that is fine at this size becomes a harder problem as models grow, so the hardware story at scale is the open question. The gains over the state-enlarging alternatives are the right comparison, but they are measured on recall and long-context language modeling, which are the tasks the method is designed for, and the paper does not deeply establish how the triadic state changes performance on the broader set of downstream reasoning tasks where state shape might matter less. And the delta-rule and forgetting combinations, while demonstrated to work, are shown to be compatible rather than shown to be jointly optimal.

Verdict: this is a clean, well-motivated architectural contribution that generalizes linear attention to a three-dimensional recurrent state and gets a large state-capacity gain for a near-negligible parameter cost, with the compatibility with the delta rule, forgetting, and chunkwise-parallel training making it practical rather than theoretical. The main caveats are the light pretraining budget, the two small model scales, and the state-memory footprint that grows with the second-key dimension, so treat the recall gains as well supported at these scales and the scaling behavior and hardware cost at frontier size as the things you would want to measure before adopting the construction.
The theoretical framing is worth stating, because it connects the method to a longer line of work. The pairwise outer product of key and value is a specific instance of writing into a memory state, and the paper places the triadic construction in the context of associative memory, where the idea of binding two or more keys to a value has a long history going back to the Hopfield-style and binding-based memory models. The novelty here is that the higher-order write is done in a way that stays compatible with the modern requirements, the data-dependent forgetting, the error-correcting delta rule, and the chunkwise-parallel training, all of which are what made linear attention competitive with attention in the first place. So the contribution is not the idea of a bigger state, it is showing that the bigger state can be built in a shape that does not break any of the machinery that makes the method practical. That compatibility is the real result, and it is what separates this from a toy generalization that works on paper but cannot be trained.
